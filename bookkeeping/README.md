# Bookkeeping

Not part of the model and not scored by it.

`inconsistencies.csv` is a running list of places where the public story changed or where sources disagree: one row per pair of accounts, with where each came from. Rows are added as they are noticed. A row is never deleted; if the disagreement is explained, the `status` column says how.

It is kept by hand. Nothing here proves that a page said what the row says it said, because the pages themselves are not saved. See "Story changes, for future research" in `HANDOFF.md`.
